I will switch the authentication storage from `localStorage` to `sessionStorage` and implement a 1-hour expiration to resolve the loading issues and ensure users re-login after inactivity.

### **1. Update Login Logic (`src/features/login/Login.tsx`)**
-   **Change Storage**: Store `accessToken` and `refreshToken` in `sessionStorage` instead of `localStorage` upon successful login.
-   **Set Expiration**: Calculate and store a `tokenExpiration` timestamp (Current Time + 1 Hour) in `sessionStorage`.
-   **Clear Old Storage**: Remove any existing tokens from `localStorage` to prevent conflicts.

### **2. Update Authentication Interceptor (`src/lib/AxiosInterceptor.ts`)**
-   **Read from Session**: Modify the request interceptor to retrieve the token from `sessionStorage`.
-   **Check Expiration**: Before every request, check if the current time has passed the `tokenExpiration`.
    -   **If Expired**: Clear all tokens from `sessionStorage` and redirect the user to `/login`.
-   **Update Refresh Logic**: Ensure the response interceptor (which handles token refreshing) saves new tokens and updates the expiration time in `sessionStorage`.

-   **Remove Duplicate Interceptor**: `axiosInstance.ts` currently has a redundant request interceptor that also reads from `localStorage`. I will remove this to ensure `AxiosInterceptor.ts` is the single source of truth for token handling.
